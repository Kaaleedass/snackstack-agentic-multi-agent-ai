SnackStack Web UI

Files:
- web.py: Flask server connected to your existing SnackStack LangGraph.
- templates/index.html: responsive chat interface.

Install Flask in your project's active environment:
    python -m pip install flask

Copy web.py into your outer SnackStack project folder.
Copy templates/index.html into the outer folder's templates subfolder.

Expected layout:
SnackStack/                  (outer project folder)
  web.py
  templates/
    index.html
  SnackStack/                (Python package)
    config.py
    graph.py
    ...

Run from the outer project folder:
    python web.py

Then open:
    http://127.0.0.1:5000

This is for local development. Do not expose Flask's debug server publicly.


Microphone and speaker buttons:
- The microphone button uses browser speech recognition (best supported in Chrome/Edge).
- Each assistant response has a Listen button using the browser's built-in speech synthesis.
- These browser buttons use browser speech features, not the Python Whisper/TTS classes.
- Microphone permissions may need to be allowed in the browser.


Voice mode behavior:
- Click the microphone once to turn voice mode on.
- Spoken input is transcribed by the browser and sent automatically.
- SnackStack automatically speaks every assistant response while voice mode is on.
- Click the microphone again to turn voice mode off.
- You can still type messages in either mode.
- There is no per-message speaker/listen button.


OpenAI voice selection:
- Select a voice from the dropdown beside the microphone (Nova, Alloy, Echo, Shimmer, Onyx, or Fable).
- When voice mode is on, assistant responses are generated by OpenAI TTS using the selected voice. You can still type messages.
- The server uses your existing SnackStack.config.openai_client and OPENAI_API_KEY configuration. TTS API usage may incur charges.
